# Invertebrate identification key — individual build brief

Question: How can observable traits make and test a two-choice key for a defined set of examples?

Goals: distinguish jointed walking legs from antennae/tentacles and observe the external coiled shell; construct valid Yes/No partitions with distinct endpoints; test all four covered examples and explain scope/identification versus phylogeny. Four selected intact examples: adult beetle, spider, shelled land snail and earthworm. No wild identification or species-level claims.

Move each virtual example to an observation tray and record walking-leg count/shell presence. Build a branching key by placing trait-question tiles on unresolved groups. Any split that creates two nonempty groups is accepted, allowing balanced or unbalanced valid keys. Rejected uninformative questions retain the attempted trait and reason. Three successful splits isolate four endpoints; no fixed forced tree. Test one shuffled card per covered example by following the actual student-built key. Four tests cover four endpoints, not repeated biological trials.

Reopening a branch preserves prior key and test history, invalidates current version tests and leaves observations intact. Reports describe evidence, actual tree, tested routes/corrections and original explanations. Supplied intact drawings and hidden test-card identities are model inputs, not field discoveries. No collecting/live handling procedure. External comprehension/device review and translation remain separate.

Science/pedagogy sources read: NPS Using Dichotomous Keys, NHM Classification Exploration, University of Wyoming Know Your Bugs, Burke Museum Eight legs always means spider. Use only relevant morphology/key concepts, not broad absolute insect/spider claims, historical species counts or physical collection steps.
